# Impermeabilize

Site institucional e catálogo de soluções em impermeabilização.

## Tecnologias
HTML5, CSS3 e JavaScript (sem build ou framework obrigatório).

## Executar
Abra `index.html` em um navegador, ou use um servidor estático local.

## Contatos
Configure WhatsApp, e-mail e endereço em `config.js`. Os campos começam vazios para evitar publicar informações fictícias.

## Conteúdo técnico
As aplicações mostradas são orientativas. A seleção final do sistema, o preparo do substrato e a execução devem seguir as fichas técnicas do fabricante e o projeto de impermeabilização.

## Imagens
As imagens de produtos exibidas na versão inicial são referências remotas de fabricantes/lojas e podem precisar ser substituídas por arquivos locais licenciados ou autorizados antes de produção.
